My thesis focused on detecting and measuring individual oil palm trees from drone imagery — using YOLOv8, YOLOv11, SAM 2.1, and Mask R-CNN across 8 altitude levels. I built an agent-in-the-loop annotation pipeline that cut labelling time by over 80%, and a generative tiling algorithm that simulates multi-altitude flights from a single drone pass. The work led to a Q1 journal publication and a successful thesis defence.

I'm interested in the boundary between computer vision and physical systems — where a model's output has a real consequence in the world. Currently exploring deep reinforcement learning, neuroscience, and applied mathematics.

Open to AI Engineer, Computer Vision, and Remote Sensing ML roles in Thailand or remote.
